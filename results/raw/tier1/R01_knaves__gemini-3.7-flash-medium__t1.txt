
- Therefore C = knave.
- C = knave makes B's claim ("C is a knave") true → B = knight.
- B = knight makes A's claim ("B is a knave") false → A = knave.
- C's claim ("both are knaves") is false since B is a knight, consistent with C = knave.

FINAL: A=knave, B=knight, C=knave
