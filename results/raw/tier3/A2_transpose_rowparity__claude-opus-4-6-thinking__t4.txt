## Reasoning

Checking the relationship between each IN/OUT pair:

**Step 1 — Transpose.** Take the transpose of IN (columns → rows).

**Step 2 — Parity-conditional complement.** For each row `r` of the original IN, count the 1s. If the count is **odd**, flip every bit in row `r` of the transposed result.

Verification on all 5 examples confirms this rule (e.g., Example 4 has all-even row sums → output is the plain transpose; Example 1 has only row 1 odd → only that transposed row is complemented).

### Applying to the query

```
IN:
1 0 1 0   ← sum=2, even
1 1 1 1   ← sum=4, even
1 1 0 1   ← sum=3, odd  → flip
1 1 0 1   ← sum=3, odd  → flip
```

Transpose:

```
1 1 1 1
0 1 1 1
1 1 0 0
0 1 1 1
```

Complement rows 2 and 3:

```
1 1 1 1
0 1 1 1
0 0 1 1
1 0 0 0
```

FINAL: 1 1 1 1; 0 1 1 1; 0 0 1 1; 1 0 0 0
