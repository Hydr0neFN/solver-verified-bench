```
[IN] ───┬──► [Transpose: INᵀ] ────────────┐
        │                                  ▼
        └──► [Parity of row r] ──► [Flip row r if odd] ──► [OUT]
```

- Rule: $\text{OUT} = \text{IN}^T \oplus (\text{IN} \cdot J) \pmod 2$, where $J$ is the all-ones matrix.
- Equivalently: row $r$ of $\text{OUT}$ is column $r$ of $\text{IN}$, bitwise inverted if row $r$ of $\text{IN}$ has odd parity.

Application to Query:
- Row 0: `1 0 1 0` → sum 2 (even) → flip = 0 → Col 0 `1 1 1 1` → `1 1 1 1`
- Row 1: `1 1 1 1` → sum 4 (even) → flip = 0 → Col 1 `0 1 1 1` → `0 1 1 1`
- Row 2: `1 1 0 1` → sum 3 (odd)  → flip = 1 → Col 2 `1 1 0 0` → `0 0 1 1`
- Row 3: `1 1 0 1` → sum 3 (odd)  → flip = 1 → Col 3 `0 1 1 1` → `1 0 0 0`

FINAL: 1 1 1 1; 0 1 1 1; 0 0 1 1; 1 0 0 0
