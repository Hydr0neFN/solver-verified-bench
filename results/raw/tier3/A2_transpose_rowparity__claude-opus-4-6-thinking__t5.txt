## Reasoning

**Step 1 — Transpose** the grid (swap rows ↔ columns).

**Step 2 — Parity flip**: for each row *i* of the original input, count the 1s. If odd, complement (flip) that row of the transposed result.

```
Rule:  OUT[i][j] = IN[j][i]  XOR  parity(row i of IN)
```

Verified across all 5 examples.

**Apply to query:**

```
IN:                  Row sums → Parity
1 0 1 0              2  →  0
1 1 1 1              4  →  0
1 1 0 1              3  →  1  (flip)
1 1 0 1              3  →  1  (flip)

Transpose:           After parity flip:
1 1 1 1   (p=0) →   1 1 1 1
0 1 1 1   (p=0) →   0 1 1 1
1 1 0 0   (p=1) →   0 0 1 1
0 1 1 1   (p=1) →   1 0 0 0
```

FINAL: 1 1 1 1; 0 1 1 1; 0 0 1 1; 1 0 0 0
