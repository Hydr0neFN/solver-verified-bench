```
[Input Grid X] ─── Transpose ───> [Grid X^T]
      │                                │
 (Row Sums)                    (Row-wise Flip)
      │                                │
      ▼                                ▼
Row i sum odd? ──── Yes ───> Invert Row i (1 ↔ 0) ───> [Output Grid Y]
               └─── No  ───> Keep Row i intact
```

Rule:
1. Transpose the 4x4 binary input grid: $Y = X^T$.
2. For each row $i$, compute the sum of row $i$ in the input grid $X$:
   - If row sum is **odd**, bitwise invert row $i$ of $Y$ ($1 \leftrightarrow 0$).
   - If row sum is **even**, keep row $i$ of $Y$ unchanged.

Query Application:
- Input Row Sums:
  - Row 0: `1 + 0 + 1 + 0 = 2` (Even) → No flip
  - Row 1: `1 + 1 + 1 + 1 = 4` (Even) → No flip
  - Row 2: `1 + 1 + 0 + 1 = 3` (Odd)  → Flip Row 2
  - Row 3: `1 + 1 + 0 + 1 = 3` (Odd)  → Flip Row 3

- Transpose $X^T$:
  - Row 0: `1 1 1 1`
  - Row 1: `0 1 1 1`
  - Row 2: `1 1 0 0`
  - Row 3: `0 1 1 1`

- Apply Flips:
  - Row 0: `1 1 1 1`
  - Row 1: `0 1 1 1`
  - Row 2: `0 0 1 1`
  - Row 3: `1 0 0 0`

FINAL: 1111; 0111; 0011; 1000
