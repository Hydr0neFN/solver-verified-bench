### Rule Extraction
1. Extract 4 parameters from `IN`:
   - $a = \text{IN}[2][0]$
   - $d = \text{IN}[2][1]$
   - $b = \text{IN}[2][2]$
   - $c = \text{IN}[0][2]$

2. Construct the persymmetric $2 \times 2$ block matrix `OUT`:
   - Top-Left: $\begin{bmatrix} 1-a & c \\ a & 1-b \end{bmatrix}$
   - Top-Right: $d \cdot I_2$
   - Bottom-Left: $b \cdot I_2$
   - Bottom-Right: $\begin{bmatrix} 1-b & c \\ a & 1-a \end{bmatrix}$

### Applying to Query
Given Query `IN`:
- $a = \text{IN}[2][0] = 0$
- $d = \text{IN}[2][1] = 1$
- $b = \text{IN}[2][2] = 0$
- $c = \text{IN}[0][2] = 0$

Thus $(a, b, c, d) = (0, 0, 0, 1)$, yielding:
- Row 1: `1 0 1 0`
- Row 2: `0 1 0 1`
- Row 3: `0 0 1 0`
- Row 4: `0 0 0 1`

FINAL: 1 0 1 0; 0 1 0 1; 0 0 1 0; 0 0 0 1
