```
[IN] ──(transpose)──> [INᵀ] ──(XOR row r with parity of row r in IN)──> [OUT]
```

- **Transformation rule**:
  - $OUT = IN^T + IN \cdot J \pmod 2$, where $J$ is the $4 \times 4$ all-ones matrix.
  - Cell formula: $OUT[r][c] = IN[c][r] \oplus \bigoplus_{k=0}^3 IN[r][k]$.
  - Equivalently: transpose $IN$, then invert row $r$ if row $r$ of $IN$ has odd parity ($\sum_c IN[r][c] \equiv 1 \pmod 2$).

- **Application to Query**:
  - Parities of $IN$ rows:
    - Row 0: `1 0 1 0` $\to$ sum 2 $\to$ parity 0 (keep)
    - Row 1: `1 1 1 1` $\to$ sum 4 $\to$ parity 0 (keep)
    - Row 2: `1 1 0 1` $\to$ sum 3 $\to$ parity 1 (invert)
    - Row 3: `1 1 0 1` $\to$ sum 3 $\to$ parity 1 (invert)
  - Transposed rows ($IN^T$):
    - Row 0: `1 1 1 1` $\xrightarrow{\oplus 0}$ `1 1 1 1`
    - Row 1: `0 1 1 1` $\xrightarrow{\oplus 0}$ `0 1 1 1`
    - Row 2: `1 1 0 0` $\xrightarrow{\oplus 1}$ `0 0 1 1`
    - Row 3: `0 1 1 1` $\xrightarrow{\oplus 1}$ `1 0 0 0`
