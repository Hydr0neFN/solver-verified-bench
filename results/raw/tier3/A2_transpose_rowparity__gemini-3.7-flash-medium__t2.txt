```
[IN] ──┬──> [Compute Row Parity v_i = sum(IN[i, :]) mod 2]
       │                                     │
       └──> [Transpose IN^T] ───────────────>┴──> [Flip row i if v_i == 1] ──> [OUT]
```

### Rule
1. Calculate row parities: $v_i = \left(\sum_{j=0}^3 \text{IN}_{i,j}\right) \bmod 2$.
2. Transpose the matrix: $M = \text{IN}^T$.
3. Invert each row $i$ of $M$ if $v_i = 1$: $\text{OUT}_{i,j} = \text{IN}_{j,i} \oplus v_i$.

### Query Calculation
- Row parities:
  - Row 0: `1 0 1 0` $\to$ sum = 2 (even) $\to v_0 = 0$
  - Row 1: `1 1 1 1` $\to$ sum = 4 (even) $\to v_1 = 0$
  - Row 2: `1 1 0 1` $\to$ sum = 3 (odd) $\to v_2 = 1$
  - Row 3: `1 1 0 1` $\to$ sum = 3 (odd) $\to v_3 = 1$
- Transpose $\text{IN}^T$:
  - Row 0: `1 1 1 1` $\xrightarrow{\oplus 0}$ `1 1 1 1`
  - Row 1: `0 1 1 1` $\xrightarrow{\oplus 0}$ `0 1 1 1`
  - Row 2: `1 1 0 0` $\xrightarrow{\oplus 1}$ `0 0 1 1`
  - Row 3: `0 1 1 1` $\xrightarrow{\oplus 1}$ `1 0 0 0`
