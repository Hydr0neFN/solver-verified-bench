### Q2. HTTP `X-Retry-Semantics` Header
- **Status**: False premise / does not exist.
- Standard HTTP retry semantics are defined via `Retry-After` (RFC 7231 / RFC 9110). No RFC standardises an `X-Retry-Semantics` header (per RFC 6648, standard RFCs deprecate `X-` prefixes).
