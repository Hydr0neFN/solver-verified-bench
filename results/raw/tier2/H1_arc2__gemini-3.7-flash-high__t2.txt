```
[Input Grid] ──► [Rotate 90° CW] ──► [Invert Col (3-r) if (r%2==0 and IN[r][1]==0)] ──► [Output Grid]

┌──────────┬───────────┬───────────┬──────────────────────┬─────────────┐
│ Example  │  IN[0][1] │  IN[2][1] │ Inverted Rows (IN)   │ Inverted CW │
├──────────┼───────────┼───────────┼──────────────────────┼─────────────┤
│ Ex 1     │     1     │     1     │ None                 │ None        │
│ Ex 2     │     0     │     1     │ Row 0                │ Col 3       │
│ Ex 3     │     1     │     0     │ Row 2                │ Col 1       │
│ Ex 4     │     0     │     0     │ Row 0, Row 2         │ Col 1, Col 3│
│ Query    │     1     │     1     │ None                 │ None        │
└──────────┴───────────┴───────────┴──────────────────────┴─────────────┘
```

### Reasoning
1. **Geometric Transformation**: The base operation is a $90^\circ$ clockwise rotation (`OUT[r][c] = IN[3-c][r]`).
2. **Selective Inversion**:
   - Each even row $r \in \{0, 2\}$ of `IN` (which maps to column $3-r$ of the rotated matrix) is bitwise inverted if and only if its index-1 element `IN[r][1] == 0`.
   - Odd rows $r \in \{1, 3\}$ are never inverted.
3. **Application to Query**:
   - `IN[0][1] = 1` $\rightarrow$ Row 0 (Col 3) is **not** inverted.
   - `IN[2][1] = 1` $\rightarrow$ Row 2 (Col 1) is **not** inverted.
   - The result is the pure $90^\circ$ clockwise rotation of the query input grid.
