- **Rule**: Positive integers with binary Hamming weight = 3 (exactly three 1s in base 2).
- **Count by bit length**:
  - 3-bit: $\binom{2}{2} = 1$ (term 1)
  - 4-bit: $\binom{3}{2} = 3$ (terms 2–4)
  - 5-bit: $\binom{4}{2} = 6$ (terms 5–10)
  - 6-bit: $\binom{5}{2} = 10$ (terms 11–20)
  - 7-bit: terms 21–25 formed as $64 + 2^j + 2^i$ ($0 \le i < j < 6$):
    - 21st: $64 + 1 + 2 = 67$
    - 22nd: $64 + 1 + 4 = 69$
    - 23rd: $64 + 2 + 4 = 70$
    - 24th: $64 + 1 + 8 = 73$
    - 25th: $64 + 2 + 8 = 74$

FINAL: 74
